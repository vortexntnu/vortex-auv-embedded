# WS2812 SPI Encoder (SAMC21 + Harmony 3)

Non-blocking WS2812/WS2812B LED driving over **SERCOM0 SPI** using a compact **3-bit encoding** and a **TC3 one‑shot** for the latch. Designed for small strips (1–10 LEDs, but scales) and minimal CPU impact.

### Pinout

- **SERCOM0 PAD[0] MOSI/DO → PA06** → wire to **WS2812 DIN** (330–470 Ω series recommended)
- **SERCOM0 PAD[1] SCK → PA07** (configured but not wired to LED; useful for probing)
- **SERCOM0 PAD[2] SS → PAXX** *(unused)*
- **Common GND** with the LED supply; shift MOSI level if LEDs at 5 V.

---

## How it works

- Each WS2812 bit (1.25 µs period) is represented by **3 SPI bits** at **~2.4 MHz**:
  - `0` → **100** (short high, long low)
  - `1` → **110** (long high, short low)
- One **color byte → 3 SPI bytes**, so **one LED (GRB) → 9 bytes**.
- Transfer is **non-blocking** via SERCOM5 SPI PLIB callback.
- **Latch/reset** (≥ **80 µs** low) is generated by **TC3** in one‑shot, also **non‑blocking**.

## Harmony / MCC settings

**SERCOM5 SPI Master**
- Mode: **SPI Master**
- **Baud**: `2,400,000 Hz` (or as close as possible)
- **Mode 0**, **MSB first**
- DO on **PAD[0]**, SCK on **PAD[1]** (SS not used)
- Pins: **PA06** (MOSI), **PA07** (SCK)

**TC3 Timer**
- Mode: **Timer**, **16‑bit counter**
- **Enable Timer Period Interrupt**
- Any clock is OK; code computes ticks from `TC3_TimerFrequencyGet()`.

## API (quick)

High-level façade (recommended):
```c
#include "led_facade.h"

void led_init(void);                         // set up encoder + bind Harmony port
void led_set(uint8_t i, uint8_t r, uint8_t g, uint8_t b);
bool led_commit_async(void);                 // start non-blocking update
bool led_busy(void);                         // true while SPI+latch in flight
```

```c
#include "ws2812_spi_enc.h"

int    ws2812_send_encoded_async(const uint8_t *buf, size_t len,
                                 ws_user_done_cb_t done, void *user);
```

## Usage example

```c
#include "definitions.h"
#include "led_facade.h"

int main(void)
{
    SYS_Initialize(NULL);     // Harmony init (pins, clocks, SERCOM5, TC3)
    led_init();               // build LUT + bind to SERCOM5/TC3

    // LED0 = green
    led_set(0, /*R*/0x00, /*G*/0x10, /*B*/0x00);
    led_commit_async();

    while (1) {
        // do other work...
        if (!led_busy()) {
            // update again if desired
            // led_set(...);
            // led_commit_async();
        }
        SYS_Tasks();          // if your project uses it
    }
}
```

## Timing notes

- At **2.4 MHz**, one SPI bit ≈ **416.7 ns**. 3 bits → **1.25 µs** (WS bit period).
- Latch requirement: **≥80 µs** line low after last bit.
- Code uses `TC3_TimerFrequencyGet()` to compute ticks, so changing TC3 clock works transparently.

## Troubleshooting

- **`discarded-qualifiers` on SPI write** → cast the buffer: `SERCOM5_SPI_Write((void*)data, len)`.
- **Undefined `TC3_TimerCounterSet/PeriodSet`** → your PLIB uses **16‑bit** names; current port calls `TC3_Timer16bit*` via small wrappers.
- **No LED update / wrong colors** → check SPI speed, Mode 0, **MSB first**, and ensure **no gaps** in the transfer (use PLIB write + callback).
- **Latch not happening** → confirm *Enable Timer Period Interrupt* for TC3 and that `TC3_TimerCallbackRegister()` is called once.
- **Wiring** → MOSI (PB02) only; don’t wire SCK or SS to the LED; add series resistor and proper level shifting if LEDs are 5 V.

---

## Design choices

- **3‑bit encoding** (0→100, 1→110) keeps SPI near ~2.4 MHz; simple, low jitter.
- Non‑blocking by design: ISR (SERCOM5) streams bytes; TC3 one‑shot handles the latch.
- Clean layering:
  - **Encoder core** (portable)
  - **Harmony port** (PLIB glue: SERCOM5 + TC3)
  - **Façade** (tiny app API)
